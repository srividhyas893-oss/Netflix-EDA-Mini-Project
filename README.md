Netflix Movies and TV Shows Analysis

Project Overview

This project performs Exploratory Data Analysis (EDA) on Netflix movies and TV shows to understand content distribution, release trends, ratings, and country-wise production.

Objectives

- Analyze movies and TV shows available on Netflix.
- Study content release trends.
- Explore ratings and country-wise distribution.
- Identify missing values and duplicate records.
- Visualize insights using Python charts.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

Dataset

The dataset contains information about Netflix movies and TV shows, including titles, content type, release dates, ratings, countries, and other details.

Data Cleaning

- Checked missing values.
- Checked and removed duplicate rows.
- Handled missing text values where appropriate.
- Prepared the dataset for analysis.

Visualizations

The notebook includes five visualizations to explore Netflix content and identify useful patterns.

Conclusion

This project uses exploratory data analysis and visualization to understand Netflix content distribution and trends.
