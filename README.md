Netflix Movies and TV Shows Analysis

Project Overview

This project performs Exploratory Data Analysis (EDA) on Netflix movies and TV shows to understand the content available on Netflix.

Objectives

- Analyze Netflix movies and TV shows.
- Compare Movies and TV Shows.
- Study content distribution by country.
- Analyze release years and content ratings.
- Visualize insights using graphs.

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

Dataset

The dataset contains information about Netflix movies and TV shows, including title, director, cast, country, release year, rating, and duration.

Data Cleaning

- Checked missing values.
- Removed duplicate records where applicable.
- Handled missing values where required.
- Prepared the data for analysis.

Visualizations

The project includes five visualizations to explore Netflix content:

1. Movies vs TV Shows
2. Content distribution by country
3. Content ratings
4. Release year analysis
5. Additional Netflix data insights

Project Files

- "Netflix_EDA_Mini_Project.ipynb" – Jupyter Notebook containing the analysis.
- "Netflix_data.csv" – Dataset (if included in the repository).
- Visualization images – Graphs generated during analysis (if uploaded).

Conclusion

This project helps us understand Netflix's content distribution, movie and TV show trends, and other useful insights through data analysis and visualization.
